Hi :> This is just for fun to me. Nothing serious

I built this project primarily as a personal playground to figure out how 2D animation and game physics actually work under the hood.just raw JavaScript, a Canvas element, and a lot of trial and error.

**Play the Live Demo here: https://hannguyen000.github.io/Mario-Game/**

The main goal wasn't "coding a game." It was about:

* Learning Animation: I’ve always wanted to know how a static drawing becomes a moving character.

* Hand-Drawn Assets: Every single frame of Alice was drawn and animated by me. I learned how to "crop" a single large image and cycle through the pieces to create the illusion of movement. I spent hours tweaking sprite sheets to make sure her run cycle didn't look like she was ice-skating...

* Physics from Scratch: Figuring out gravity, "air resistance," and why characters keep falling through the floor (collision detection is harder than it looks!).
  
**Controls**
* On PC: A / D or Left / Right to move, W or Up to jump.
* On Mobile: I added some translucent buttons so you can play it on the go.
